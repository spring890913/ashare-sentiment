方案 A · GitHub Actions + Pages（推荐）

零成本云端

已预置 .github/workflows/daily_sentiment_update.yml。推送到 GitHub 并开启 Pages（Source 选 /docs）后，每个交易日 15:15 北京时间自动拉取全 A 5,200+ 股收盘数据、刷新图表并发布网页，手机/电脑直接收藏访问。 

git init && git add . && git commit -m "init"
# Push to GitHub -> Settings -> Pages -> main /docs
# Optional Secret: WEBHOOK_URL (飞书/钉钉/企微推送)

方案 B · 本机 / VPS / NAS 定时更新

3.5秒增量

单次增量更新仅需 ~4 秒（腾讯批量行情 API），收盘后自动写入历史 CSV，盘中运行仅生成实时预览不污染历史。运行安装脚本即可配置工作日 15:15 定时任务 + 本地交互服务（带“一键刷新”按钮）。 

# 安装工作日 15:15 crontab 定时更新
bash setup_cron.sh
# 启动本地实时看板（含一键刷新接口）
.venv/bin/python serve_dashboard.py --port 8765

方案 C · 每日收盘 Webhook 推送

免盯盘

自动识别飞书、钉钉、企业微信或通用 Webhook 格式，每日 15:15 将仓位指令、风格切换、距离触发阈值及大面率预警直接推送到群聊。 

export WEBHOOK_URL="https://open.feishu.cn/..."
.venv/bin/python daily_update.py --notify
